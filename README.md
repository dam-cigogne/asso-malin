# Asso malin

L'appli de ton groupe (club, association, équipe). Gratuite, sans publicité, données chiffrées.

👉 **Essayer :** https://dam-cigogne.github.io/asso-malin/

## Ce que ça fait
- Agenda et événements du groupe, inscriptions, membres, annonces
- Fonctionne sur téléphone (iPhone et Android) comme une vraie appli, même hors connexion
- Les données du groupe sont **chiffrées** : seuls les membres peuvent les lire
- Pas de publicité, aucune donnée revendue

## Avoir sa propre appli (gratuit)
Chaque groupe a **son propre serveur** : tes données restent chez toi.
Le guide pas à pas (même sans compte GitHub ni Cloudflare) :
👉 https://dam-cigogne.github.io/asso-malin/tuto.html

En résumé : copier (« forker ») ce dépôt sur ton GitHub, activer GitHub Pages, créer un serveur gratuit sur Cloudflare, coller son adresse dans l'appli.

## Mettre à jour
👉 https://dam-cigogne.github.io/asso-malin/maj.html

## Passer la main
Un administrateur peut sauvegarder le groupe dans un fichier protégé par mot de passe, et son successeur le remet dans sa propre appli (« Remettre mon groupe depuis une sauvegarde », puis « Envoyer tout le groupe »).
