Mettre à jour mon appli

Un clic, deux minutes. Tes données ne bougent pas.

  1. Récupérer la nouvelle version

    • Ouvre ton GitHub : github.com/TONNOM/asso-malin
    • Si tu vois « This branch is X commits behind », touche Sync fork puis Update branch. Sinon, tu es déjà à jour.

  2. Attendre 1 à 2 minutes

    GitHub remet ton appli en ligne tout seul.

  3. Relancer l’appli

    Sur chaque téléphone : ferme l’appli complètement, rouvre-la, deux fois. La nouvelle version s’affiche (Réglages › Aide et à propos).

    Ton serveur Cloudflare n’a presque jamais besoin de mise à jour. Si c’est le cas, la note de version le dit et te donne le nouveau code à coller (étape « Créer le serveur » du guide).
