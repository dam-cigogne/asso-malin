Installer ton Asso malin

Guide pas à pas, sans rien savoir en informatique. Compte une heure, une seule fois. Tout est gratuit pour un groupe comme le tien.

Au bout de ce guide, tu auras ta propre appli (à ton adresse) et ton propre serveur : tes données sont chez toi, chiffrées, et personne d’autre n’en dépend. Tu peux aussi voir une démo avant de te lancer.

🧩 Avant de commencer : à quoi sert chaque chose ?

Il y a trois pièces, chacune avec son rôle :

  • GitHub = le magasin de l’appli. Il garde les fichiers de l’appli et les met en ligne à une adresse en github.io. Tu ouvres cette adresse sur ton téléphone, tu l’ajoutes à l’écran d’accueil, et c’est ton appli. GitHub ne garde aucune donnée de ton groupe.
  • Cloudflare = le coffre du groupe. C’est le serveur : il garde les données (membres, événements, inscriptions), toutes chiffrées, et les fait passer d’un téléphone à l’autre. Il envoie aussi les notifications. Son adresse se termine par workers.dev.
  • L’appli sur les téléphones = la clé. Elle vient de GitHub et parle à Cloudflare.
Ne pas confondre les deux adresses : celle en github.io ouvre l’appli ; celle en workers.dev est à coller dans l’appli, à l’écran « Serveur du groupe ».

Les deux comptes sont gratuits pour un groupe comme le tien. Sans serveur, l’appli marche, mais seule : rien ne se synchronise entre les téléphones.

  1. Créer ton compte GitHub

    GitHub est le « garage » où ton appli sera rangée. C’est gratuit.

    • Va sur github.com/signup
    • Entre ton e-mail, un mot de passe, un nom d’utilisateur (il apparaîtra dans l’adresse de ton appli : choisis-le court, par exemple le nom de ton club).
    • Confirme avec le code reçu par e-mail.
    Note ton nom d’utilisateur : on l’appelle TONNOM dans ce guide.

  2. Copier l’appli dans ton GitHub (« fork »)

    Tu fais ta propre copie d’Asso malin. Elle sera à toi, personne ne peut la modifier.

    • Ouvre github.com/dam-cigogne/asso-malin
    • Touche le bouton Fork (en haut à droite), puis Create fork.
    • Tu arrives dans github.com/TONNOM/asso-malin : c’est ta copie.

  3. Mettre l’appli en ligne (« Pages »)

    • Dans ta copie, touche Settings (Paramètres), puis Pages dans la colonne de gauche.
    • Sous Source : « Deploy from a branch ». Sous Branch : choisis main et / (root), puis Save.
    • Attends 1 à 2 minutes et rafraîchis : l’adresse de ton appli apparaît.
    Ton appli est à l’adresse https://TONNOM.github.io/asso-malin/
    Ouvre-la : elle marche déjà, mais il lui faut encore un serveur pour partager le groupe entre téléphones. C’est la suite.

  4. Créer ton compte Cloudflare

    Cloudflare héberge ton « serveur » : une petite boîte aux lettres chiffrée entre les téléphones du groupe. Gratuit, sans carte bancaire.

    • Va sur dash.cloudflare.com/sign-up
    • Entre ton e-mail et un mot de passe, confirme l’e-mail reçu.
    • Si on te propose un abonnement, choisis toujours Free / Gratuit.

  5. Créer la base de données

    • Dans Cloudflare, menu de gauche : Stockage et bases de données (Storage & databases) › D1 SQL Database.
    • Créer une base de données (Create database). Nom : asso-malin-db. Valide.
    Les noms des menus changent de temps en temps. Si tu ne trouves pas exactement le même, cherche le mot « D1 ».

  6. Créer le serveur (« Worker »)

    • Menu : Calcul / Workers & Pages › Créer › Créer un Worker.
    • Nom : asso-malin (ou ce que tu veux). Touche Déployer (Deploy).
    • Puis Modifier le code (Edit code). Efface tout ce qu’il y a dans la fenêtre, et colle le code ci-dessous. Touche Déployer.

  7. Brancher la base de données au serveur

    • Ouvre ton Worker › Paramètres (Settings) › Liaisons (Bindings) › Ajouter › Base de données D1.
    • Nom de la variable : écris exactement DB (deux lettres majuscules).
    • Choisis la base asso-malin-db, puis Déployer.
    C’est l’étape où on se trompe le plus : la variable doit s’appeler DB, rien d’autre.

    Ne montre jamais la clé privée à personne. Les clés ne sont pas conservées sur cette page : si tu la fermes avant d’avoir fini, refais « Fabriquer mes clés » et recopie les deux.

  9. Relier l’appli à ton serveur

    • Dans ton Worker, copie son adresse : elle ressemble à https://asso-malin.TONCOMPTE.workers.dev (visible en haut de la page du Worker).
    • Ouvre ton appli (https://TONNOM.github.io/asso-malin/), touche Créer un groupe, colle l’adresse, Tester et enregistrer. Si « ok » s’affiche, c’est gagné.
    • Donne un nom à ton groupe, ton prénom, et tu es l’administrateur.

  10. Mettre l’appli sur l’écran d’accueil

    • iPhone : ouvre l’adresse dans Safari › bouton Partager › Sur l’écran d’accueil.
    • Android : dans Chrome › menu ⋮ › Installer l’application (ou Ajouter à l’écran d’accueil).
    Ensuite, invite les membres depuis l’appli (Groupe › Inviter) : ils reçoivent un message avec un code.

🔁 Mettre à jour plus tard

Quand une nouvelle version d’Asso malin sort, un clic suffit : page « Mettre à jour mon appli ».

🤝 Quand tu passes la main

Le plus simple : nomme ton successeur administrateur dans l’appli, puis invite-le sur ton Cloudflare (Gérer le compte › Membres › Inviter) et ton GitHub (Settings › Collaborators). Rien ne bouge.

Ou chacun chez soi (tu gardes ton compte, il a le sien) :

  1. Toi : Réglages › Sauvegarde et code › « Sauvegarder (fichier) », avec un mot de passe. Envoie-lui le fichier et le mot de passe.
  2. Lui : suit ce guide pour créer son serveur et son appli.
  3. Lui, sur l’écran d’accueil : « Remettre mon groupe depuis une sauvegarde », le fichier, le mot de passe.
  4. Lui : Réglages › Personnalisation › Serveur du groupe : colle l’adresse de son serveur, puis touche « Envoyer tout le groupe ».
  5. Les membres : Réglages › Personnalisation › Serveur du groupe : ils collent la nouvelle adresse (envoie-la leur par message).
